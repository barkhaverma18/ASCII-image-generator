# ASCII-image-generator
# Image to ASCII Art Converter using Python

This project converts a digital image into ASCII art using Python and the Pillow (PIL) library.
ASCII art represents images using text characters based on pixel brightness.

---

## Project Description
The Image to ASCII Art Converter takes an input image, processes it using image resizing and grayscale conversion,
and maps each pixel’s intensity value to a corresponding ASCII character.
The final output is a text-based visual representation of the original image.

This project is suitable for beginners and college minor projects.

---

## Objectives
- Load an image file into the program
- Resize the image while maintaining aspect ratio
- Convert the image into grayscale
- Map pixel intensity values to ASCII characters
- Display the ASCII art as text output

---

## Technologies Used
- Python 3
- Pillow (PIL) Library
- Google Colab / Jupyter Notebook
- VS Code / Local Python Environment
